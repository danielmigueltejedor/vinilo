# Security policy

Please report a vulnerability in Vinilo privately through
[GitHub private vulnerability reporting](https://github.com/getnodalia/vinilo/security/advisories/new),
not in a public issue or pull request. Say which version and edition you ran (Linux, Vinilo
Nodalia for macOS or Vinilo Native for macOS), and how to reproduce the problem.

Nodalia maintains Vinilo and handles every report. Only the latest release receives security
fixes.
